## 03. Bill Splitter

**Learning Source:** freeCodeCamp – Python

A beginner-level Python project that calculates a restaurant bill and divides the total cost equally among a group of friends.

### Features
- Calculates the total cost of food and drinks.
- Calculates the tip amount.
- Adds the tip to the original bill.
- Divides the final bill equally among friends.
- Rounds the amount each person needs to pay to two decimal places.

### Concepts Practiced
- Variables and data types
- Integer and floating-point numbers
- Arithmetic operations
- Assignment operators (`+=`)
- Mathematical calculations
- Output formatting using f-strings
- Rounding numbers using `round()`

### Example Calculation

### What I Learned

Through this project, I practiced performing mathematical calculations in Python, managing variables, calculating percentages, and formatting numerical output.
